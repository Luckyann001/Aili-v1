# AILI logo set v1 (drawn by Claude from Lucky's concept)
- logo-mark.svg: symbol only (ribbon A, orb, orbit, satellite)
- logo-primary.svg / logo-primary-dark.svg: stacked lockup, light and dark backgrounds
- logo-horizontal.svg: symbol | wordmark for navigation
- logo-mono-ink.svg / logo-mono-light.svg: single-colour versions
- logo-icon.svg: app icon on a rounded square
- favicon.svg: simplified for 16-48 px (no orbit)
Notes: the wordmark letters are drawn as paths (no font needed). The tagline is live text set in Inter: convert it to outlines once Inter is installed, or keep Inter loaded. Highlight colour #E3987A is derived from Copper for the gradient. No trademark search has been done for "AILI".

## Updates (M0, Oct 9 2026)
- `*-outlined.svg`: the five lockups with a tagline (primary, primary-dark, horizontal, mono-ink, mono-light) with the tagline converted to paths. The originals are kept unchanged beside them. **The app uses the outlined versions.**
  - Generated by `scripts/outline-logo-text.py` from the app's own Inter file (`@fontsource-variable/inter`, latin, weight 400), shaped with HarfBuzz so kerning and letter-spacing match a browser.
  - Requirements: Python 3 with `fonttools`, `brotli` and `uharfbuzz` (authoring only, not an app dependency).
  - Checked against the live-text originals rendered in Chrome with Inter loaded: 0.12–0.20% of pixels differ, all anti-aliasing along letter edges.
- `logo-horizontal-compact.svg`: symbol, divider and AILI wordmark with no tagline, for the navigation bar. The mark and divider are unchanged; the wordmark is moved down to centre on the mark.
- `logo-mono-light.svg` and its outlined version now have a **transparent background** (the #282724 rectangle was removed), so they sit on any dark surface.
